## ⚡ 3-Minute Setup

### Step 1: Open Extensions Page
**Chrome:**
1. Open Chrome browser
2. Type in address bar: `chrome://extensions`
3. Press Enter

**Edge:**
1. Open Edge browser
2. Type in address bar: `edge://extensions`
3. Press Enter

### Step 2: Enable Developer Mode
- Look for toggle in **top-right corner**
- Switch **Developer mode** to **ON**
- Page will refresh with new options

### Step 3: Load Extension
1. Click **"Load unpacked"** button
2. Navigate to: `c:\Users\shaur\Documents\hls_downloader`
3. Select the folder
4. Click **"Select Folder"**

### Step 4: Verify Installation ✅
- Extension icon appears in toolbar (purple download arrow)
- Name shows: "HLS Video Downloader"
- Status: No errors
